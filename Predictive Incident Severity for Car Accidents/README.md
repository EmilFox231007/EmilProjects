# Predictive Model for Incident Severity (ANWB)

## We worked with ANWB, who do insurance, roadside assistance, traffic information, etc. They gave us an extensive and sensitive traffic dataset that included accidents types, seasons, exact locations, the times any event happened, etc. With that we made a predicitve ML model that predicts incident severity on the road using the data provided to us. 

### The main parts of this project were:
- Making sure everything was compliant with EU GDPR Safety Regulations  
- Performed extensive data cleaning (checked for duplicates, handling missing values, visualized outliers, etc)
- Managed the datasets in SQL queries (merged datasets, encoded categorical variables, did Correlational Analysis)
- Created ML models to predict incident severity
    - Best performing one was a Random Forrest Classifier, F1 score: 95
